# 🍽️ Recipe Application

A modern Android application built with **Jetpack Compose** that allows users to explore, search, and save their favorite meal recipes. The app demonstrates clean architecture, offline-first capabilities, and best practices in Android development.

---

## ✨ Features
* 🔍 **Smart Search:** Search for meals by name with debounced query optimization.
* ⭐️ **Favorite Recipes:** Save and remove favorite meals stored locally for offline access.
* 🌐 **Network Operations:** Fetch recipe data dynamically from external REST APIs.
* 🎨 **Modern UI:** Built entirely with **Jetpack Compose** using **Material 3** guidelines.

---

## 🛠️ Tech Stack & Architecture
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material Design 3)
* **Architecture:** MVVM (Model-View-ViewModel) & Clean Architecture principles
* **Local Persistence:** Room Database
* **Networking:** Retrofit & OkHttp
* **Asynchronous & Reactive:** Kotlin Coroutines & StateFlow / Flow
