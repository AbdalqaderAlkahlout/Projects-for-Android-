# 📝 Modern Note Taking Application

A feature-rich Android application built with **Jetpack Compose** that enables users to create, edit, organize, and search their daily notes seamlessly. The app highlights clean architecture, local state management, and offline persistence using Room.

---

## ✨ Key Features
* ✍️ **Create & Edit Notes:** Easily draft, update, and manage personal notes.
* 🔍 **Instant Search:** Search through saved notes dynamically with responsive UI updating.
* 💾 **Offline-First Storage:** Local data persistence powered by Room Database.
* 🎨 **Material 3 UI:** Clean, responsive, and modern user interface using Jetpack Compose.
* 🗑️ **Delete & Manage:** Quickly remove or organize existing notes with smooth interactions.

---

## 🛠️ Tech Stack & Architecture
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material Design 3)
* **Architecture:** MVVM (Model-View-ViewModel) & Clean Architecture principles
* **Local Database:** Room Persistence Library
* **Asynchronous Operations:** Kotlin Coroutines & StateFlow / SharedFlow
* **Navigation:** Jetpack Compose Navigation

---
